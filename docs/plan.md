# Plan — report outline and figure plan (D0b)

Replaces the Phase-0 plan (2026-10-03, HEAD `75e6551`). **No chapters are written until you say so.**
The report is one story: problem → antenna → single-layer phantom → layered sphere → what the
fields say the array senses → classification → lobe phantom → imaging → CST voxel head → conclusions.
For every step: what we built, how we simulated it, how the S-parameters / fields changed, what we concluded.

Inputs: **INV** = `docs/00_inventory.md`, **CR** = `docs/01_claims_register.md` (claim IDs), **OQ** =
`docs/open_questions.md`, **N** = `docs/notation.md`, **P01–P05** = context packs (P05 = imaging-session extraction).

## Figure tags and conventions

Tags: **[SS]** screenshot you provide · **[CODE]** regenerated by a script in `docs/figures/src/` · **[EXIST]** existing figure (path given) · **[IMG]** imaging-session output (P05).
*Status*: **have** = input exists in the repo now; **need X** = waiting for pack/screenshot/data X; **fix** = existing figure needs regeneration (reason given).

[CODE] chart conventions: antenna names T1–T6 (never port numbers); path names reflection / neighbour / second-neighbour / opposite; dB vs GHz over **3.2–4.2 GHz** (the band common to every dataset; v2 also has 2.8–3.2 GHz, used only where stated); 3.4 GHz marked; one fixed colour per stage across the report (Normal, MCI, Mild, Moderate, Severe; defined once in `docs/figures/src/style.py`); same y-range across compared panels; every stage comparison has a "stage − healthy" panel with a noise band, and the caption names which noise:
- **measurement noise** = `typical` profile (0.25 dB, 2°, −70 dB floor), N §6;
- **symmetry floor** = antenna-to-antenna spread inside one file (circulant for symmetric heads, mirror floor for staged lobe designs);
- **solve-to-solve SD** = v1 vs v2 sweep repeats (≈ 0.15 dB on the ratios; not a mesh repeat, N §9.1);
- **mesh yardstick** = Healthy_sliced − v2 Normal (lobe chapters).
Captions say what to look at and give the key number.

## Chapter 5 — Electric-field analysis: what the array actually senses (bridge to imaging)

Field maps for each excitation; route of each path type (opposite path ≈ 99 % of its Born sensitivity in air, 0.3 % in brain, CR B2); penetration (outer ~1–1.5 cm; CR B3; lobe study: outermost ~8 mm of cortex determined, CR H3) → CSF/cortex visible, hippocampus/MCI invisible (CR B4); sensitivity kernels.

Equation to write with every symbol defined (from `imaging/study_i2_hfss.py`, N §8):
dS_ij(f) = −(jωε₀Z₀ / 4V²) ∫_V Δε(r) E_i(r)·E_j(r) dV, Δε = Δε_r − jΔσ/(ωε₀), E_i = field with antenna i driven at V = 1 V incident, all other ports matched 50 Ω (Z₀), e^{+jωt}.
Limit to state with it: on the HFSS data the Born prediction is only 0.11–0.44 of the true dS size (v2, CR F3) and 0.23–0.35 (lobe, CR H11); κ(f) fitted on Mild absorbs this.

Field data available: `data/fields/` = **v2 Normal only**, 3.4 / 3.6 / 3.8 GHz, 3 mm grid ±90 mm, plus T1 wide (±120 mm, 4 mm) at 3.6 GHz (git-ignored, on disk). No fields for the stages, the lobe phantom or other frequencies.

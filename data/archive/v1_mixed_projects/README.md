# Archived dataset v1 (superseded 2026-10-01)

Four HFSS solves used for prompts 01A-03 and the imaging study (results up to commit e9bced0).
Normal and Severe came from one HFSS project, Mild and Moderate from another (project confound);
Severe was exported only from 3.2 GHz at 2 MHz steps. Replaced by the re-solved set in data/raw/
(all stages in one project, 2.8-4.2 GHz, plus MCI). Kept for comparison and reproducibility:
to rerun on it, point config.yaml data.raw_dir / data.manifest at this folder.
